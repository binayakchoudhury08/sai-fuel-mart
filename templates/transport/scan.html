Set up page scanning (owner, one time, free)

Scanning reads the handwritten bill with Google Gemini’s free tier. To switch it on:

  1. Open aistudio.google.com/apikey → sign in with a Google account → Create API key → copy it (starts with AIza…).
  2. Vercel → your project → Settings → Environment Variables → add GEMINI_API_KEY = that key.
  3. Deployments → latest → ⋯ → Redeploy. Then come back here.

Free tier: Google may use the photos to improve its products. Bill pages hold vehicle numbers and amounts only. {% if user.role == 'owner' %} After setting it up, test it in Settings → System → Page reader (AI) check.{% endif %}
