Set up (5 minutes, free, no card)

  1. Open aistudio.google.com/apikey and sign in with a Google account (the business Gmail is best).
  2. Press Create API key → choose “Create key in new project” → copy the key (starts with AIza…).
  3. Vercel → your project → Settings → Environment Variables → Name GEMINI_API_KEY, Value = the key → Save.
  4. Deployments → latest → ⋯ → Redeploy. Then come back here and press Test page reader.

Free tier: Google may use the photos to improve its products, and the limits (pages per minute / per day) are set by Google and can change — see them at aistudio.google.com/rate-limit. About 10–15 pages a day is light use. If you ever want the photos kept private or higher limits, link a billing account in AI Studio (paid tier, a few rupees a month at this volume) — nothing else changes here.
